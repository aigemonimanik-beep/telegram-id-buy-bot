# আইডি কেনার বট — হোস্টিং ফাইল (Render ফ্রি)

এই ফোল্ডারের ফাইলগুলো নতুন কেনার বটের (ইউজাররা আইডি বিক্রি করে, তুমি যাচাই
করে টাকা দাও) হোস্টিংয়ের জন্য। লাইভ বটের ফাইল নয় — এটা আলাদা কপি।

## ফাইলগুলো কী

- `bot.py` — তোমার কেনার বট, হোস্টিংয়ের জন্য তৈরি। Muse-এর ভল্ট ছাড়াও
  চলে; টোকেন `TELEGRAM_BUY_BOT_TOKEN` থেকে নেয়। আর `/` আর `/ping`-এ "OK"
  জবাব দেয়, যাতে Render বুঝতে পারে বট বেঁচে আছে।
- `render.yaml` — Render-কে বলে: ফ্রি Web Service বানাও, `python3 bot.py`
  দিয়ে চালাও।
- `requirements.txt` — খালি। বট শুধু Python-এর নিজের জিনিস ব্যবহার করে,
  আর কিছু লাগে না।

## Render-এ চালু করার ধাপ

1. **GitHub:** এই ফোল্ডারের ফাইলগুলো GitHub-এ একটা রিপোজিটরিতে দাও
   (নাম যেমন `telegram-buy-bot`)।
2. **Render:** render.com-এ গিয়ে New → Web Service → ওই রিপোজিটরি বেছে
   নাও। Free প্ল্যান বেছে নাও।
3. **টোকেন — খুব জরুরি:** Render-এর ড্যাশবোর্ডে Environment → Add
   Environment Variable → নাম `TELEGRAM_BUY_BOT_TOKEN`, মান তোমার বটের
   টোকেন (Telegram-এ @BotFather থেকে: `/mybots` → তোমার বট → API Token)।
   টোকেন কখনো এই ফাইলে লিখবে না, আর চ্যাটে কাউকে পাঠাবে না।
4. **Deploy** চাপো। বট চালু হলে Telegram-এ বটকে `/start` দিয়ে দেখো।
5. **জাগিয়ে রাখা:** UptimeRobot-এ (ফ্রি) একটা মনিটর বানাও, প্রতি ৫ মিনিটে
   তোমার Render লিংকের `/ping`-এ পিং দেবে — নইলে বট ১৫ মিনিট চুপ থাকলে
   ঘুমিয়ে যাবে।
6. বট চালু হলে অ্যাডমিন প্যানেল থেকে আসল ক্যাটাগরি (যেমন Instagram 2FA,
   Instagram কুকিজ, Facebook কুকিজ), প্রতিটার দাম আর নিয়ম বসাও।

## সত্যি কথা — সীমা

1. **একসাথে একটাই বট চলবে।** Render-এ বট চালু করলে Muse-এর এখানের
   (বা অন্য কোথাও) একই বট বন্ধ করে দিতে হবে। দুটো একসাথে চললে Telegram
   409 ভুল দেখাবে আর দুটোই থেমে যাবে।
2. **ফ্রি Render-এ ডাটা মুছে যায়।** ক্যাটাগরি, জমা দেওয়া আইডি, মাস্টার
   শিট, ব্যালেন্স — এগুলো ফাইলে থাকে। Render ফ্রি সার্ভিস রিস্টার্ট হলে
   ফাইল মুছে যায়, বট আবার খালি থেকে শুরু হবে। তাই আসল ক্যাটাগরি, দাম
   আর নিয়ম Render-এ আবার বসাতে হবে। নিয়মিত মাস্টার শিট CSV ডাউনলোড
   করে নিজের কাছে রেখো।
3. **ঘুমিয়ে যায়।** ফ্রি Web Service ১৫ মিনিট কেউ না ডাকলে ঘুমিয়ে যায়;
   প্রথম মেসেজে জাগতে ৩০-৬০ সেকেন্ড লাগতে পারে। UptimeRobot-এর ৫
   মিনিটের পিং এটা ঠেকায়।
4. **একটাই ফ্রি সার্ভিস ২৪ ঘণ্টা চলে।** Render ফ্রি ৭৫০ ঘণ্টা/মাস দেয় —
   এক মাস ৭৪৪ ঘণ্টা, তাই একটা সার্ভিসই পুরো মাস চলবে। বিক্রির বট আর
   কেনার বট দুটোই Render ফ্রিতে একসাথে ২৪ ঘণ্টা চালাতে পারবে না।
